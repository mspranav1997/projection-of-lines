# Projection of Lines: 3D Visualiser

An interactive web app for engineering graphics students to see how a straight line is projected
on the horizontal plane (HP) and vertical plane (VP), with the front view, top view and a rotatable
3D view side by side.

Made by PRANAV M S, CAPE College, Punnapra.

## Use it
Open `index.html` in any modern browser. It works offline: the 3D library is included in `lib/`.

## Publish on GitHub Pages
1. Upload all files in this folder to a repository (keep the `lib` folder).
2. Go to Settings, then Pages. Under Build and deployment choose "Deploy from a branch", branch `main`, folder `/ (root)`.
3. After a minute the app is live at `https://<your-username>.github.io/<repository-name>/`.
